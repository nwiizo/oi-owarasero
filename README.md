# oi-owarasero

仕事・学習・家事・個人制作などで止まった場面を責めずに省察し、見えていなかった前提と次の一歩を見つけるための対話型Agent Skillです。Claude CodeとCodexの両方に、プラグインとして導入できます。

## 書籍との関係

本Skillは、次の書籍で扱う5ステップと語彙を、AIエージェントとの対話手順へ再構成したものです。

- 書名：『おい、とりあえず終わらせろ　そうすれば「動けない自分」が変わるから』
- 著者：nwiizo（ぬうぃぞう）
- 出版社：ダイヤモンド社
- ISBN：9784478124192
- [Amazon](https://link.amazon/B07pyNg3Z)
- [国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/books/R100000137-I9784478124192)

「決めろ→分けろ→始めろ→出せ→回せ」「自分的完了／他者的完了」「動ける粒度」「反省ではなく省察」「感情と構造を分ける」「4行のメモ」など、本書の考え方を対話の流れに組み込んでいます。

書籍本文の代わりになる要約や、本文・図版の転載物ではありません。手元の悩みを振り返り、次の一周を自分で選ぶための対話用Skillです。

## できること

- 止まった一場面を、自己否定から切り離して構造から振り返る
- 相手がいるタスクでは、自分的完了と他者的完了のずれを見つける
- 5ステップのどこで詰まっているかを対話から見立てる
- 相手の背景を確かめ、相手が次に判断・行動できる内容と出し方を考える
- 次に変えることを一つだけ選ぶ
- 動ける粒度の一動作と、始めるきっかけを決める
- 本書の4行のメモで、省察を次の行動へつなげる

一人で進めるタスクでは、学んだことを実際の課題に使う、作ったものを試す、決めた場所を片付けるなど、小さく一周した結果から完了を確かめます。習慣づくりでは、今日の一回に終わりの線を引きます。

問いは依存関係に沿って進め、別々に答えられる問いだけを最大3問の短いラウンドにまとめます。気持ちが強い場面や、考える負担が大きい問いでは一問ずつ進めます。本人が自分の言葉で次の一歩を決められるよう、AIは考える過程を支えます。

## インストール

### Claude Codeのプラグインとして導入する

Claude Code内で次のコマンドを実行します。

```text
/plugin marketplace add nwiizo/oi-owarasero
/plugin install oi-owarasero@oi-owarasero
```

インストール後、`/reload-plugins`を実行するかClaude Codeを再起動してください。

### Codexのプラグインとして導入する

ターミナルで次のコマンドを実行します。`codex plugin`に対応したCodex CLIが必要です。

```sh
codex plugin marketplace add nwiizo/oi-owarasero
codex plugin add oi-owarasero@oi-owarasero
```

インストール後、新しいスレッドで使ってください。

プラグインの配置と導入方法は、[Claude Codeの公式ドキュメント](https://code.claude.com/docs/en/plugin-marketplaces)と[OpenAIの公式ドキュメント](https://developers.openai.com/plugins/build/plugins)に沿っています。

### スキル単体で導入する

Claude CodeやCodexにインストールを任せる場合は、次の依頼文をそのまま貼り付けてください。

```text
https://github.com/nwiizo/oi-owarasero のスキルを確認し、
oi-owaraseroを今使っているAIエージェントで使えるようにインストールしてください。
```

コマンドでインストールする場合は、[skills CLI](https://skills.sh/)でClaude CodeとCodexへまとめて追加できます。

```sh
npx skills add nwiizo/oi-owarasero \
  --skill oi-owarasero \
  --agent claude-code codex \
  --global
```

リポジトリ単位で使う場合は、`--global`を外してください。

## 使い方

Claude Codeにプラグインとして導入した場合は、プラグイン名を付けて呼び出します。

```text
/oi-owarasero:oi-owarasero 提案書を出せないまま3日止まっています
```

スキル単体で導入した場合は、従来どおり`/oi-owarasero`で呼び出します。

Codexでは、入力欄で`$`を入力し、候補から`oi-owarasero`を選んで相談内容を続けます。

```text
$oi-owarasero 提案書を出せないまま3日止まっています
```

本書の考え方を身近な場面に当てはめると、たとえば次のように相談できます。

- 仕事：相手が何を判断できればよいかを確かめず、提案書を一人で直し続けている
- 学習：「もっと勉強してから」と学び続け、現実の問題に取り組み始められない
- 家事：部屋を片付けたいが、どこまでやれば今日は終わりにできるか決まっていない
- 個人制作：アプリの全体設計を考え続けて、最初の機能を作り始められない
- 調査：条件に合う候補があるのに、「もっと良いものがあるかも」と比較をやめられない
- 習慣：日記を一日休むと「まとめて書かなければ」と思い、再開できない

Skillを明示しなくても、先延ばし、完璧主義、着手や提出への怖さ、試した後の停滞を振り返りたい依頼では、説明文をもとに選ばれることがあります。

## 対話の着地点

対話の最後は、次の形まで進めば十分です。相手への確認が不要な場合は「誰に何を確かめるか」を省くなど、その場面に合う項目だけを残します。

```markdown
## 今回の省察

- 何が起きたか：
- 自分は何を前提にしていたか：
- 実際にはどうだったか：
- 次は何を変えるか：

## 次の一歩

- 最初の一動作：
- 始めるきっかけ：
- 一周したとわかる印：
- 誰に何を確かめるか：
```

## 指示の設計

[GPT-6 Astraの公式プロンプティングガイド](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices)を参照し、次の方針をスキル本文へ反映しています（2026年9月8日確認）。

- ユーザーの依頼を標準手順より優先し、訂正や補足を受けても、それまでに決まったことを引き継ぐ。
- 本人が考えるための対話と、依頼された実作業を区別する。実作業では許可済みの範囲を進め、確認が必要な部分だけ回答を待つ。
- 短い段落と身近な言葉で応答し、見出しや決まり文句を繰り返さない。
- 実作業の分担は利用先の方針に従い、検証は変更の影響に見合う範囲で行う。

Astra向けの推奨事項を、対話型スキルの用途に合わせて取り入れています。モデルを指定する設定は含まず、Claude CodeとCodexで共通のスキルを使います。

## 構成

```text
.
├── .agents/
│   └── plugins/
│       └── marketplace.json
├── .claude-plugin/
│   ├── marketplace.json
│   └── plugin.json
├── .codex-plugin/
```

共通のAgent Skills形式を採用し、両方のプラグインが`skills/oi-owarasero/SKILL.md`を読み込みます。各マーケットプレイスの`source`は、このリポジトリのルートを指します。

## ローカルで確認する

このリポジトリのルートで実行してください。Claude Codeでは、そのセッションだけプラグインを読み込めます。

```sh
claude --plugin-dir .
```

Codexでは、ローカルのマーケットプレイスを登録してインストールします。

```sh
codex plugin marketplace add .
codex plugin add oi-owarasero@oi-owarasero
```

配布する内容を更新したら、両方の`plugin.json`の`version`を同じ値へ更新してください。
